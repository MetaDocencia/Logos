# Organigrama

`MD_organigrama_2026.svg` es el organigrama de MetaDocencia en formato editable.

## Cómo editarlo

Se abre y se edita con **Inkscape**, un programa de diseño vectorial libre y gratuito disponible en https://inkscape.org

1. Abrir el archivo desde Archivo, Abrir.
2. Guardar una copia con un nombre nuevo antes de empezar. El archivo original no se modifica.
3. Cambiar los textos con la herramienta Texto. Si un texto no se puede editar es porque está convertido a trazado, y en ese caso no se modifica.
4. Cambiar un color desde Objeto, Relleno y borde, escribiendo el código en el campo RGBA y agregando FF al final. Por ejemplo, para el rojo institucional se escribe `C83737FF`.
5. Exportar desde Archivo, Exportar imagen PNG, con el ancho en píxeles que corresponda a la pieza.

## Qué se puede modificar y qué no

Se puede cambiar los nombres de las áreas y de las personas, y ajustar el tamaño de la pieza completa.

No se puede cambiar la tipografía, modificar el logo o sus proporciones, agregar colores fuera de la paleta ni deformar la pieza al ajustarla.

## Cuándo se actualiza

Cada vez que cambia la estructura del equipo. El archivo lleva el año en el nombre, así que al actualizarlo conviene guardar la versión nueva con el año que corresponda y dejar la anterior como antecedente.
