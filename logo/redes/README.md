# Imágenes de perfil

Las plataformas recortan la imagen de perfil en círculo, así que estas versiones llevan el isotipo centrado y con margen suficiente para que no se corte el globo de diálogo.

- **`MD_perfil_fondo-blanco`.** La versión por defecto.
- **`MD_perfil_fondo-azul`.** Para plataformas de fondo claro donde el logo sobre blanco se pierde.
- **`MD_perfil_transparente`.** Para componer sobre otro fondo.

Cada una está en PNG de 800 x 800 píxeles, que es más que suficiente para cualquier plataforma, y en SVG por si hay que ajustarla.

## Medidas de referencia

- LinkedIn, página de organización: 400 x 400
- Instagram: 320 x 320
- Facebook: 360 x 360
- Bluesky y Mastodon: 400 x 400
- YouTube: 800 x 800
